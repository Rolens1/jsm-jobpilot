# Feature 02: Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement InsForge OAuth authentication (Google and GitHub), dedicated Login page UI, OAuth callback handler, session persistence, and Next.js route protection middleware.

**Architecture:** Install `@insforge/sdk@latest` and configure browser client in `lib/insforge-client.ts` with environment variables. Build a sleek, token-compliant Login page at `app/(auth)/login/page.tsx` supporting Google and GitHub OAuth redirects. Build the OAuth callback handler at `app/(auth)/callback/page.tsx` to handle the `insforge_code` exchange and redirect to `/dashboard`. Implement route protection middleware in `middleware.ts` for `/dashboard`, `/profile`, `/find-jobs`, and `/find-jobs/[id]`.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript strict, `@insforge/sdk@latest`, Tailwind CSS v4 `@theme` design tokens, Lucide React icons.

**Spec:** `context/build-plan.md` (Feature 02), `context/architecture.md`, `context/ui-tokens.md`, `context/ui-rules.md`.

## Global Constraints

- Never use hardcoded hex values or raw Tailwind color classes (e.g. no `bg-purple-500`, `#7C5CFC`). Use `@theme` tokens: `bg-accent`, `text-text-primary`, `border-border`, etc.
- All cards must use `bg-surface border border-border rounded-2xl` with white backgrounds.
- Client Separation: Browser auth interactions occur in Client Components using `lib/insforge-client.ts`.
- Server Components by default: only mark components `"use client"` when state, lifecycle, or browser events are required.
- Update `context/progress-tracker.md` and `context/ui-registry.md` after completion.

## Review Focus

1. **OAuth Redirect Failure / Cancellation**: If the user cancels or an OAuth error occurs during redirect or exchange, show a clear, user-friendly error state on `/login`.
2. **Session Persistence**: Ensure sessions persist across page refreshes via `insforge.auth.getCurrentUser()`.
3. **Route Protection**: Unauthenticated access to `/dashboard`, `/profile`, `/find-jobs`, and `/find-jobs/[id]` must redirect to `/login` with a `redirectTo` or return parameter.
4. **Already Authenticated Redirect**: Visiting `/login` when already authenticated should redirect to `/dashboard`.
5. **Clean TypeScript & Build**: Zero TypeScript errors and clean `npm run build` compilation.

  const anonKey = process.env.NEXT_PUBLIC_INSFORGE_ANON_KEY;

    throw new Error("Missing InsForge environment variables (NEXT_PUBLIC_INSFORGE_URL, NEXT_PUBLIC_INSFORGE_ANON_KEY)");
